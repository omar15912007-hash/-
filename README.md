# نبض الذكر (Nabd Al-Dhikr) - v1.0.0

تطبيق إسلامي حديث ومتطور مبني بالكامل بأحدث تقنيات أندرويد الأصلية (**Kotlin**, **Jetpack Compose Material 3**, **Clean Architecture + MVVM**)، بحجم فائق الصغر (**2.22 MB** فقط) واستهلاك يكاد لا يُذكر لموارد الجهاز والذاكرة (RAM).

---

## 🌟 مميزات التطبيق

1. **موسوعة الأذكار الشاملة والمحققة (171 ذكراً عبر 28 قسماً):**
   - مستقاة بالكامل من كتاب *حصن المسلم من أذكار الكتاب والسنة*.
   - تشكيل لغوي دقيق، فضل الذكر، تخريج الحديث الشريف، عداد تكرار تفاعلي، وترجمة إنجليزية كاملة.
   - تشمل أذكار الصباح والمساء (30 ذكراً لكل منهما)، أذكار النوم والاستيقاظ، الصلاة والأذان، المسجد والمنزل، الطعام واللباس والسفر، الأدعية القرآنية والرقية الشرعية، وأدعية تفريج الهم والكرب.

2. **محدد اتجاه القبلة الذكي فلكياً (Smart Qibla Finder):**
   - حساب دقيق لزاوية القبلة الكروية (Great-Circle Forward Azimuth) والمسافة إلى الكعبة المشرفة بصيغة Haversine.
   - تصحيح الشمال الجغرافي الحقيقي (Geographic True North) بالاعتماد على الانحراف المغناطيسي للأرض (`GeomagneticField`).
   - تنعيم قراءات البوصلة الدائرية عبر مرشح تمرير منخفض (Low-Pass Filter) ودوران مستمر 60fps عبر أقصر مسار زاوي دون ارتداد عند عبور 0°/360°.
   - إبرة فاخرة متوجة بمجسم الكعبة المشرفة وحزامها الذهبي، مع اهتزاز (Haptic Feedback) وتوهج زمردي عند محاذاة القبلة بدقة ($\pm 3^\circ$).
   - التعرف التلقائي على اسم المدينة والدولة بالعربية عبر `Geocoder`، وتنبيه ذكي لمعايرة الحساس عند الحاجة.

3. **السبحة الإلكترونية الذكية (Tasbih):**
   - عدّاد تسبيح رقمي مع خيارات الأهداف (33، 100، أو مفتوح) واهتزاز تفاعلي عند كل تسبيحة واهتزاز مميز عند الإتمام.

4. **البحث السريع والمفضلة:**
   - محرك بحث فوري يدعم التصفية مع وبدون علامات التشكيل.
   - حفظ الأذكار المفضلة للوصول السريع إليها بدون إنترنت.

5. **التنبيهات والإشعارات الذكية:**
   - جدولة يومية تلقائية لأذكار الصباح والمساء عبر `WorkManager`.

6. **إعدادات وتخصيص متقدم:**
   - التحكم بحجم الخط عبر سلايدر يدعم RTL وتطبيقه مركزياً عبر التطبيق.
   - تفعيل أو تعطيل الاهتزازات التفاعلية، وضبط مواعيد التذكيرات وتخزينها محلياً عبر `DataStore Preferences`.

## 🛠️ متطلبات التشغيل والبناء (Build Environment)

- **بيئة العمل:** مسار المشروع على القرص `F:\omar\New folder`
- **حزمة Java (JBR):** `F:\android studio\jbr`
- **حزمة Android SDK:** `F:\android studio2`
- **الحد الأدنى لـ SDK:** Android 8.0 (API 26)
- **الهدف (Target SDK):** Android 15 (API 35)

### أوامر البناء السريع:
لإنشاء نسخة الـ Release فائقة الصغر ونقلها إلى سطح المكتب مباشرة:
```powershell
cmd /c "F:\omar\New folder\build_apk.bat"
```
أو عبر Gradle:
```powershell
$env:JAVA_HOME = "F:\android studio\jbr"
$env:PATH = "F:\android studio\jbr\bin;$env:PATH"
.\gradlew.bat assembleRelease
Copy-Item "app\build\outputs\apk\release\app-release.apk" "$env:USERPROFILE\Desktop\NabdAlDhikr.apk" -Force
```
